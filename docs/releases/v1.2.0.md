# Easy Edge Apps 1.2.0

Website icons, command-line automation, and an updated native Windows setup experience in one self-contained PowerShell script.

## What's new

- **Get website icons:** Enter an HTTPS address and select **Get icon**. Setup discovers ICO and PNG favicons, previews the result, and saves it only when you choose **Add website** or **Save changes**. Background lookup is cancellable; failures and stale results preserve the current icon. Retrieved icons travel with App Kits.
- **Command-line automation:** `-Unattended` explicitly approves supported operations without setup dialogs or confirmation prompts, preserves validation and `-WhatIf`, returns structured results, and provides explicit success/failure exit codes. Kit import supports selected `-AppNames`; encrypted operations continue to accept caller-managed `SecureString` values only.
- **Built-in help:** `--help`, `-h`, `-Help`, and PowerShell's standard `-?` display help without opening setup or performing an operation.
- **Refreshed native controls:** Embedded application branding, Windows-style command and field icons, accessible tooltips, and enlarged-font layouts. Ctrl+Backspace deletes words without inserting control characters and retains native undo.
- **Animated space background:** Original, locally rendered stars move independently of the mouse, with gently eased parallax. The **Motion** checkbox pauses animation. Reduced-motion, remote-session, high-contrast, and inactive-window behavior keep accessibility and resource use in view.

## Fixes and hardening

- UI types now load under source-versioned namespaces, preventing an older assembly in a persistent PowerShell session from hiding newly added controls such as `IconCheckBox`.
- Strict JSON numeric grammar rejects malformed numbers that the platform reader otherwise accepts.
- Unavailable Favorites addresses have bounded, sanitized display text and remain ineligible for import; browser files are not modified.
- Icon previews and editor reset, cancellation, address changes, disposal, and enlarged-text scrolling have regression coverage.

## Upgrade and download

Download `EasyEdgeApps.ps1` from this release's assets. It is the only runtime file required. Close the old setup window and run the updated script as the Windows user whose shortcuts you manage. Existing saved apps, shortcuts, version-1 App Kits, and older command-line operations remain compatible; there is no data migration or automatic script updater.

`SHA256SUMS.txt` contains the script's SHA-256 checksum. Compare it with `Get-FileHash .\EasyEdgeApps.ps1 -Algorithm SHA256`. The script is unsigned; a matching checksum detects a mismatched download, not publisher identity or code safety.

Windows PowerShell 5.1 and PowerShell 7 on Windows are supported. No elevation, external modules, browser-policy changes, services, or background launcher are required. These remain Edge app-window shortcuts, not fully registered Progressive Web Apps.

## Privacy and limits

**Get icon** is opt-in network access to the entered website and its declared HTTPS icon or redirect destinations, with normal certificate validation. It uses no third-party favicon service, browser cookies, stored passwords, default Windows/proxy credentials, authorization header, or referrer. A website can direct requests to other HTTPS hosts reachable from the computer; use trusted sites and never enter URLs containing secrets. Typing, starting setup, importing kits, and checking apps do not retrieve icons automatically.

Page responses are bounded to 512 KiB and icon downloads to 1 MiB, with bounded dimensions, redirects, and cancellation deadlines. Images become Windows-compatible 128-pixel ICOs in memory before explicit saving. SVG-only, sign-in-protected, or automation-blocking sites may require a trusted local `.ico` file instead.

**Encrypted exports remain experimental and require independent security review before production use.** Encryption protects only the exported file, not installed settings, shortcuts, recovery files, or browser sessions. Known-answer and tamper tests are not an independent cryptographic audit. Keep credentials out of URLs and notes, and share strong passphrases separately.

Ownership, preflight, per-app staging, locking, and caught-error rollback remain in place. A whole kit is not one atomic transaction; earlier successes can remain after a later failure. Check and Repair does not verify website access or repair sign-in.

## Verification

Ten isolated suites cover shortcut ownership and rollback, JSON portability and bounds, Favorites, favicon discovery and conversion, real background workers and cancellation, App Kits and repair, cryptographic vectors, encrypted-file interoperability, public CLI binding, and both native GUI surfaces. The runner covers Windows PowerShell 5.1 and PowerShell 7, including 12-, 18-, and 24-point layouts within 1024 by 768 and stale UI-assembly reloads.

Live public-site favicon retrieval is also checked separately from the deterministic offline suite. Real-site sign-in, physical high-DPI/high-contrast/Narrator use, cross-computer handover, and OneDrive/network-filesystem behavior still require acceptance checks on the intended computers. See the README, automation guide, security guidance, and App Kit specification for details.
