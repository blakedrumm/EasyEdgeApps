# Easy Edge Apps 1.3.1

Author: Blake Drumm (blakedrumm@microsoft.com)

Taskbar pinning assistance for saved website shortcuts, available in both the portable script and per-user MSI.

## What's new

- **Pin to taskbar...** sits beside Desktop and Start menu. Save and select a website to enable it.
- The command opens File Explorer with the owned saved shortcut selected, preferring Start menu and falling back to Desktop. Right-click that shortcut, choose **Show more options** if needed, then **Pin to taskbar**.
- Saved addresses, icons, notes, and Edge profiles remain unchanged. Unsaved editor changes are not applied. Missing or modified shortcuts fail safely with repair guidance.
- The button has a native pin icon, keyboard access, and an accessible description. The handoff status remains compact at enlarged text sizes.

## Windows owns the pin

This is a manual Windows workflow, not automatic pinning or a saved taskbar checkbox. The tool does not invoke hidden pinning verbs, edit taskbar registry data, bypass policy, or claim that a pin was created. Pin availability and window grouping remain controlled by Windows and Edge.

Taskbar pins do not travel in App Kits and are not maintained by Check and Repair or the MSI. Unpin before removing a website; unpin and pin again if a changed address, profile, or icon leaves a stale taskbar copy. Check that the pinned entry opens the intended website. Use Edge's own **Install this site as an app** when registered web-app identity is required.

## Download and upgrade

Close setup and run **EasyEdgeApps-1.3.1-x64.msi** in the same Windows account, or replace the portable **EasyEdgeApps.ps1**. Existing saved websites and preferences remain compatible. Automatic update checks and debug logging remain off by default.

The MSI, launcher, and script are unsigned. Obtain them from the official release and compare downloads with **SHA256SUMS.txt**; checksums do not authenticate publisher identity. The matching **WiX-5.0.2-source.zip** remains included with its complete license notices. Encrypted App Kit exports remain experimental pending independent security review.

## Verification

Thirteen isolated application suites cover both Windows PowerShell 5.1 and PowerShell 7. New tests cover quoted Explorer paths, Start/Desktop fallback, shortcut ownership, saved profile preservation, WhatIf, recovery blocks, button enable/reset states, unsaved edits, Explorer failures, and 12/18/24-point layouts within 1024 by 768. Automated taskbar tests never open real Explorer windows or change taskbar pins.

A separate native smoke check verified selection of the intended synthetic shortcut in File Explorer. The final Windows menu command, pin creation, and pinned launch require manual checks on the intended computer. MSI lifecycle and compiled-launcher checks remain part of release validation and CI.
