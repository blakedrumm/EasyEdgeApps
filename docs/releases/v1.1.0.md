# Easy Edge Apps 1.1.0

Set up someone's everyday websites once. Restore and maintain that familiar setup whenever they need help.

## What's new

- **Edge Favorites bar import:** Choose a local Edge profile, browse nested bar folders, and add selected HTTPS websites. Unsupported links show a reason; duplicate websites and shortcut-name collisions are handled without changing Edge's favorites.
- **Portable App Kits:** Export and import named website collections with placement choices, helper notes, and portable generated or embedded custom icons. Preview additions, updates, conflicts, and exact destination changes before approval.
- **Optional password protection:** Encrypt the entire exported kit with a portable, authenticated format shared by Windows PowerShell 5.1 and PowerShell 7. Password confirmation, in-memory unlock, bounded input validation, and no plaintext fallback are included.
- **Check Apps and Repair Selected:** Read-only diagnostics followed by explicitly approved repair of missing owned files. Modified artifacts, unrelated files, stale approvals, and pending recovery are preserved.
- **Accessible native dialogs and CLI:** Large-text scrolling layouts, masked password fields, selection previews, structured results, and noninteractive-safe command handling.

The runtime remains one self-contained PowerShell script. Existing saved apps and the Install, List, Open, and Remove commands remain compatible. No administrator rights, external modules, browser-policy changes, services, or background launcher are required.

## Download

Download `EasyEdgeApps.ps1` from this release's assets. It is the only file needed to run the tool. Review it before running it in the Windows account that will use the shortcuts.

`SHA256SUMS.txt` contains the script's SHA-256 checksum. Compare it with `Get-FileHash .\EasyEdgeApps.ps1 -Algorithm SHA256`. A matching checksum detects a mismatched download; it is not a code-signing certificate.

## Safety notes

**Encrypted exports are experimental and require independent security review before production use.** The implementation uses platform PBKDF2-HMAC-SHA256 and RFC 7518 A256CBC-HS512, with known-answer and tamper tests. Passing tests is not a cryptographic audit.

Encryption protects only the exported file, not installed URLs, notes, shortcuts, icons, recovery data, or browser sessions. Use a strong unique passphrase, share it separately, and keep credentials and tokens out of URLs and notes. Forgotten passwords cannot be recovered.

Imports support up to 100 apps per batch. Each app uses the existing ownership, staging, mutex, and rollback protections; a whole kit is not one atomic transaction. If a later app fails, earlier successful apps remain and results identify what was not attempted. Check and Repair does not test website access or repair sign-in.

## Verification

Nine isolated suites cover the original shortcut safety tests, JSON types and bounds, Favorites, App Kits and repair, RFC cryptographic vectors, encrypted file interoperability and failure handling, the public CLI, and both GUI surfaces. Both Windows PowerShell 5.1 and PowerShell 7 are covered, including encrypted transfers in both directions and 12-, 18-, and 24-point GUI layouts capped at 1024 by 768.

Real-site sign-in, physical high-DPI/high-contrast/Narrator use, cross-machine handover, and OneDrive/network-filesystem behavior still require acceptance checks on the intended computers. See the repository README, security guidance, and App Kit format specification for details.
