# Easy Edge Apps 2.0.0 Preview 1

**Unsigned engineering prerelease for Windows 11 x64. Not production-ready, not a completed one-for-one migration, and not a replacement for the stable v1.4.0 release.** Live legacy migration and rollback remain disabled. Use synthetic data in an isolated directory.

## Download and Run

Download `EasyEdgeApps-2.0.0-preview.1-x64.zip` and `SHA256SUMS.txt` from this release. Compare the archive's SHA256, then extract the entire ZIP to a new directory. Keep all files together: the manager needs the supplied XBF, PRI, .NET runtime and Windows App SDK files.

From the extracted folder, open PowerShell and run:

```powershell
Get-FileHash ..\EasyEdgeApps-2.0.0-preview.1-x64.zip -Algorithm SHA256
& .\EasyEdgeApps.Manager.exe --isolated-root (Join-Path $PWD 'preview-data')
```

Adjust the archive path to its actual download location. Isolated mode redirects website data and shortcuts into `preview-data` and blocks actual browser, network, pin and installer actions. The compiled manager does not require a separately installed .NET runtime. The original PowerShell distribution is retained separately in the payload.

The MSI is supplied for separately authorized disposable-Windows acceptance only. **Do not install it over your everyday installation:** it shares the predecessor's upgrade identity, and the compiled install/upgrade/repair/uninstall lifecycle has not been accepted. The portable ZIP is the recommended way to inspect this preview.

## Included

- Compiled C#/.NET 10 LTS manager, CLI, website launcher and image worker, with a WinUI 3 interface and Windows App SDK 2.4.
- Permanent website identities, stable rename paths, original appearance, preferences, profile/window controls, Check Apps, kits and Favorites workflows.
- Safer catalog/journal bounds, ownership-checked recovery, migration rollback cleanup and strict malformed-update validation.
- Command-time selection locking, named removal confirmation and failed-icon recovery that preserves draft notes.
- Native job-handle ownership, explicit owned-child termination and awaited helper cancellation.
- The retained PowerShell application, including import-preview validation and matching native cleanup fixes.

## Limits and Trust

- Real Edge/profile/shutdown, taskbar/grouping, compiled installer lifecycle, clean-machine, cross-session migration, physical DPI and spoken accessibility acceptance remain outstanding.
- Production signing, signed update positives, and independent encryption/legal review remain outstanding. Encrypted kits are experimental.
- Checksums detect changed bytes; they do not authenticate a publisher. The production publisher pin is empty, so these unsigned assets cannot become trusted automatic updates.
- The portable payload is 427,222,548 bytes. The selected self-contained launcher is 141,518,994 bytes per website; retained transaction backups add storage. Allow several GiB of free working space for testing.
- The two full published UI runs observed 626-631 MiB peak memory and 2.87-3.71-second first saves. These are individual observations, not benchmarks or performance parity.

No real browser profile, pin, installed product or signing credential was used during the local validation. Source publication and this prerelease do not clear the remaining acceptance gates.
